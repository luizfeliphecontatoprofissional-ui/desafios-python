# 🐍 Python & Análise de Dados — Roadmap de Estudos

Repositório dedicado ao meu aprendizado em Python, SQL e análise de dados. Aqui organizo exercícios, registro minha evolução e planejo projetos práticos para transformar os conhecimentos estudados em soluções reais.

Meu objetivo é construir uma base sólida em programação e bancos de dados, direcionando minha formação principalmente para **Análise de Dados e Business Intelligence**, sem deixar de explorar automação e Engenharia de Dados como possibilidades futuras.

## 🎯 Direcionamento

- **Foco principal:** Análise de Dados e Business Intelligence.
- **Base técnica:** Python, SQL, bancos de dados, Excel e estatística.
- **Complementos:** automação, integração de dados e desenvolvimento web básico.
- **Possibilidades futuras:** Engenharia de Dados e, mais adiante, Ciência de Dados.

Sou estudante de Análise e Desenvolvimento de Sistemas (ADS) e estagiário na área de TI. Tenho contato acadêmico com programação, desenvolvimento web e bancos de dados, e utilizo este repositório para documentar minha evolução.

**Inglês:** nível B2. Pretendo continuar desenvolvendo o idioma por meio da leitura de documentação, cursos e materiais técnicos.

## 🟠 Fase 2: Banco de Dados, Excel & Introdução ao BI

- [ ] Subconsultas (*subqueries*).
- [ ] `CASE WHEN`.

### Excel

- [ ] Revisar fundamentos e funções essenciais.
- [ ] Funções condicionais e de busca: `SE`, `SOMASES`, `CONT.SES`, `PROCV` e `PROCX`.
- [ ] Tabelas dinâmicas.
- [ ] Gráficos, indicadores e organização de relatórios.
- [ ] Power Query: importação, transformação e limpeza de dados.

### Power BI — fundamentos

- [ ] Conhecer a interface e importar fontes de dados.
- [ ] Transformar dados com Power Query.
- [ ] Criar relacionamentos básicos entre tabelas.
- [ ] Criar medidas iniciais com DAX.
- [ ] Desenvolver um primeiro dashboard simples.

### Projeto

- [ ] **Banco de Dados de Suporte de TI:** modelar um cenário fictício de chamados, usuários, equipamentos e categorias; desenvolver consultas para analisar indicadores. Utilizar dados sintéticos, sem informações internas da empresa onde trabalho.

## 📚 Estratégia de Estudos

- Priorizar SQL e praticar consultas regularmente.
- Manter Python em prática, aplicando-o aos assuntos estudados e aos projetos.
- Revisar Excel a partir de exercícios práticos, concentrando os estudos nas lacunas identificadas.
- Aprender Power BI gradualmente, começando pela preparação dos dados e pelos dashboards básicos.
- Utilizar documentação, cursos e materiais em inglês para manter e desenvolver o inglês técnico.
- Registrar nos READMEs dos projetos a pergunta investigada, a origem dos dados, o método utilizado, os resultados e as conclusões.
- Marcar uma etapa como concluída quando conseguir aplicar o conhecimento de forma independente, e não apenas após assistir às aulas.

## 📝 Observações

Este roadmap é um planejamento em evolução, não uma lista rígida de tecnologias que precisam ser dominadas. Os conteúdos poderão ser reorganizados conforme minha experiência, meus projetos, a graduação e as oportunidades profissionais.

A prioridade atual é construir uma base consistente em **SQL, Python aplicado a dados, Excel e Power BI**, mantendo Desenvolvimento Web como conhecimento complementar e explorando Engenharia de Dados conforme a evolução dos estudos.
